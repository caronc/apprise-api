##
## Apprise Backend Installation
##
## You should only have 1 of the 3 items uncommented below.

## 1. Uncomment the below line to pull the main branch of Apprise:
# apprise @ git+https://github.com/caronc/apprise

## 2. Uncomment the below line instead if you wish to focus on a tag:
# apprise @ git+https://github.com/caronc/apprise@custom-tag-or-version

## 3. The below grabs our stable version (generally the best choice):
apprise == 2.0.1

## Apprise API Minimum Requirements
# Language selection relies on a Django internal; raise after testing a new major
django < 7
gevent
## newer gunicorn releases no longer pull it in as a base dependency
gunicorn[gevent]

## for webhook support
requests

## 3rd Party Service support
paho-mqtt >= 2.1.0
gntp
cryptography
# Pretty Good Privacy (PGP) Provides mailto:// and deltachat:// support
PGPy
# Provides smpp:// support
smpplib
# For xmpp:// support
slixmpp >= 1.16.0
# Provides amqp:// support for AMQP 0.9.1
pika
# Provides amqp:// support for AMQP 1.0. It has no Linux wheel, so the
# Dockerfile compiles it; it is left out of pyproject.toml so local and
# CI test runs do not need a compiler.
python-qpid-proton

# prometheus metrics
django-prometheus
