# Store Badges

Unmodified SVG artwork downloaded from the store owners.

- Google: https://partnermarketinghub.withgoogle.com/brands/google-play/google-play/lockups-icons-badges/?folder=86718
- Apple: https://tools.applemediaservices.com/api/badges/download-on-the-app-store/black/en-us?size=250x83 (replace `en-us` with the locale listed below).

Google files are `GetItOnGooglePlay_Badge_Web_color_<language>.svg`, except Japanese, which is the supplied `Print_color_Japanese.svg` vector asset.

Apple's badge service currently returns English artwork for Hindi. Hindi uses that official English badge with a localized accessible label; other supported languages use their own artwork.
